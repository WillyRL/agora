# Agora

A native macOS (SwiftUI) client for Hermes Bots. See `GLOSSARY.md` for vocabulary, `docs/adr/` for decisions and `docs/design/` for the visual design reference (match it when building UI).

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues for WillyRL/agora (via `gh`). See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `GLOSSARY.md` + `docs/adr/`. See `docs/agents/domain.md`.
